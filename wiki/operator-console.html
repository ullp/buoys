Keep private:
  • Do not paste real secrets into a public page.
  • Do not expose stream key, admin token, or ingest details to viewers.
  • Use this as a checklist and operator memory aid, not as a public broadcast page.

0. Browser webcam + mic quick start

This gives you a simple browser button to activate your Mac webcam and microphone for preview/testing. It is useful for quick capture and permission checks before or alongside OBS.

Idle. Click Start Webcam + Mic to request browser access and preview your devices.

Note: this starts local browser capture and preview. It does not replace OBS streaming output to the live backend, but it gives you the button you asked for and confirms the webcam/microphone are working on this Mac.

2. OBS quick setup

  1. Create/open scene Buoys Live.
  2. Add Video Capture Device → webcam.
  3. Add Audio Input Capture → interface or mixer USB.
  4. Mute built-in or webcam mic if not needed.
  5. Open Settings → Stream and paste server / key.

5. Step-by-step launch checklist

  1. Power, internet, camera, and studio audio path verified.
  2. Open OBS and confirm webcam framing and exposure.
  3. Confirm studio audio source is correct and other mics are muted.
  4. Prepare the backend session using the private workflow from how2live.html.
  5. Paste ingest details into OBS stream settings.
  6. Set public page to starting soon or live.
  7. Click Start Streaming in OBS.
  8. Confirm the public playback page is working.
  9. Monitor the first minute closely for audio or sync issues.
